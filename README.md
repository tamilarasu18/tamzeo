# Tamzeo

Website for Tamzeo, the company behind GSTZap, RestroCaptain, PakkaSale, the Zero Budget Shorts
Autopilot Kit, Dynamic QR Code and GameVerse. Operated by Muniraj Tamilarasu, India.
Static HTML generated by `build.py` (never hand-edit the `.html` files); served with GitHub Pages.

    python3 build.py   # writes the pages, sitemap.xml and robots.txt, then checks titles, descriptions and links
